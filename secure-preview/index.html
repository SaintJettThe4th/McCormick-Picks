Rules

McCormick Pick'em Rules
1. Picking: Each user picks a winner for every game, every week (Weeks 1-18).
2. Saving: You must tap Save Picks to lock in your choices. Unsaved picks are lost if you leave the page.
3. Deadline: Picks lock at each game's kickoff time. You can change and re-save freely until then.
4. Missed Picks: If you don't pick a game before kickoff, the home team is automatically assigned as your pick.
5. Ties: If a game ends in a tie, both users receive a tie (not a win or loss). Ties appear orange in Games and neutral in Picks.
6. Records: Displayed as W-L-T (Wins-Losses-Ties).
7. Money: $10 per win difference, max $100. The user with fewer wins owes the difference.
8. Scores: Final scores sync automatically from ESPN. No manual entry needed.
